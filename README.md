# Simple Calculator\n\nA clean and modern calculator built with vanilla HTML, CSS, and JavaScript.\n\n## 🚀 Live Demo\n\n**[▶️ Play the calculator here!](https://jjs123alt.github.io/simple-calculator/)**\n\n## ✨ Features\n\n- ➕ Addition, subtraction, multiplication, and division\n- 🔢 Decimal point support\n- ❌ Clear button to reset\n- ⌫ Delete button to remove the last digit\n- 🎨 Modern UI with gradient background\n- 📱 Fully responsive design\n\n## 📁 Files\n\n- `index.html` - Calculator markup\n- `style.css` - Styling and layout\n- `script.js` - Calculator logic\n\n## 🎮 How to Use\n\n1. Click the **\"Play the calculator here!\"** link above to open it instantly\n2. Click number buttons to enter values\n3. Click operator buttons (+, −, ×, ÷)\n4. Click = to see the result\n5. Use C to clear or DEL to delete the last digit\n
